# NEIS 생기부 점검

나이스(NEIS) 입력 전 기재 금지어·맞춤법·명사형 어미·중복 문장을 자율 점검하는 웹 도구입니다.

- 바로 사용: https://woorimalsam-lab.github.io/neis-check/
- `index.html` 파일을 브라우저에서 열기만 해도 동작합니다(별도 설치/서버 불필요).
- 특정 학교에 종속되지 않은 **일반 배포용**입니다.

## 주요 기능

| 메뉴 | 내용 |
|---|---|
| 📝 생기부 점검 | 기재 금지어(빨강)·순화 대상(노랑) 감지와 원클릭 치환/삭제, 맞춤법·띄어쓰기 교정(수정 이유 설명 포함), 명사형 어미(-함.) 추천·일괄 교정, 중복 문장 경고, 글자 수(공백 제외) |
| 📊 엑셀 일괄 점검(담임교사) | 창체·행특 엑셀 파일을 올려 학생별 일괄 점검 |
| 📊 엑셀 일괄 점검(교과교사) | 세특 엑셀 일괄 점검, 중·고등학교 성취기준 조회(고등: 공통/일반/진로/융합 선택) |
| 📖 대체표현 사전 | 금지어·대체어 목록 조회 |
| ❓ 기재요령 Q&A | 기재요령 문답 |
| 📂 자료실 | 성취기준·기재요령 관련 공개 자료 링크 |
| 👥 사이버 감사 | 학생 간 복사·붙여넣기 유사도 검사 |

화면 오른쪽 위 해/달 아이콘으로 다크·라이트 모드를 바꿀 수 있습니다(기본: 다크).

## 사전 관리

점검 규칙은 모두 `index.html` 안의 사전으로 관리되며, 한 줄만 추가하면 반영됩니다.

**기재 금지어·대체어** (`BANNED_WORDS`)
```js
"유니세프": "국제 아동구호 기구|기관명 대신 '국제 아동구호 기구' 등으로 순화하세요.",
"서울대": "기재 불가|특정 대학명은 기재할 수 없습니다.",
```
- `"단어": "대체어|설명"` 형식입니다. 대체어가 `기재 불가`이면 빨강(삭제 권장), 그 외에는 노랑(대체어로 치환)으로 표시됩니다.
- 동형어 오탐(예: '아마존 열대우림', '고려대장경')은 `isValidBannedMatch`의 문맥 조건으로 제외합니다.

**맞춤법·띄어쓰기** (`SPELLING_RULES`)
```js
"진학율": ["진학률", SPELL_REASONS.yul],
"역활": ["역할", "'역할(役割)'이 표준어입니다."],
```
- `"잘못된 표기": [올바른 표기, 수정 이유]` 형식이며, 수정 이유는 점검 결과에 `💡 수정 이유`로 표시됩니다.
- 자주 쓰는 이유는 `SPELL_REASONS`에 모아 재사용하고, 동형어 예외(예: '과정의 일부로', '구지가')는 `SPELL_GATES`에 둡니다.

## 개인정보

- 입력한 내용과 업로드한 엑셀 파일은 **브라우저 안에서만 처리**되며 서버로 전송되지 않습니다.
- 학생 명단은 코드에 포함되어 있지 않습니다.
- 방문자 수 표시는 익명 카운트만 기록합니다(입력 내용과 무관).
